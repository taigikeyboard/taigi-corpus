# sinpak_900leku — 新北市 900例句

Taiwanese (台語) example sentences from the 新北市政府教育局 104 學年度
(2015) 閩南語字音字形 900 例句工作坊.

- **896 example sentences** (one `Document` per 例句)
- `text` = 例句漢字; `metadata.parallel_poj` = aligned 例句臺羅 (diacritic Tâi-lô)
- `title` = 詞條漢字 (the headword each sentence illustrates)
- `script` = `han`
- `tags`: `subset:900leku`
- `id`: `sinpak_900leku:<編號>` (e.g. `sinpak_900leku:001`)

## Upstream

- GitHub: <https://github.com/Taiwanese-Corpus/Sin1pak8tshi7_2015_900-le7ku3>
- The scraper fetches the maintained `minnan900.json` from the raw GitHub URL.
- `make build-sinpak_900leku` re-fetches in full; the latest scrape is cached
  at `raw/scrape-<timestamp>.json`.
